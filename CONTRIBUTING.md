# Contributing / 参与完善

[Open an issue](https://github.com/ttttmh0215/research-diagram-studio/issues) with a figure request, a workflow problem, or a style suggestion. Include the input you can share, the expected result, and the step where help is needed.

For a new style or domain, provide a small visual brief, a realistic example, and its source. Keep the main skill concise; put domain-specific detail in linked references. Preserve scientific relationships and the user's selection stage.

When contributing a workflow change, check an actual outcome: a rendered figure, asset coverage, alpha transparency, or native PPT editability, as appropriate. Keep private manuscripts, credentials, personal paths, and unlicensed reference collections out of contributions. Record credits for third-party figures separately from the project's MIT material.

欢迎通过 Issue 分享使用问题、图稿需求或新风格建议。提供可公开的输入、期望效果，以及需要改进的具体步骤。

新增风格或领域时，请附简短绘图 brief、真实案例和来源。主 Skill 保持简洁，领域细节放入链接的参考文件。修改工作流后，检查实际图稿、素材覆盖、透明通道或 PPT 可编辑性；第三方图片单独注明出处与原有条款。
