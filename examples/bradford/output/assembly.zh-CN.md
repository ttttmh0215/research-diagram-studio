# 手动组装

1. 打开Bradford-editable-frame.pptx，保留第1页作为组装页；第2页只用于对照编号。另存一个组装副本。
2. 对照素材编号定位图，在“选择窗格”中找到形如ASSET_A01_O01的空白形状。
3. 推荐选中该空白形状，打开“设置形状格式”，用对应PNG作图片填充。空白形状已经按PNG比例设置尺寸，并位于文字层下方，因此不用将图片拉伸，也不易遮住屏幕文字。透明背景在填充时保留。
4. 也可常规插入PNG，按CSV里的英寸坐标设置大小和位置，并保持纵横比。仪器屏幕上的TXT_screen_A、TXT_screen_595和TXT_screen_nm需要放在仪器图片上方；比色皿A10位于仪器前方。
5. A05用在两处输入瓶，A06用在三处加试剂场景，A07用在两个蓝色反应样品位置。已准备全部10张图案，不需要重新生图。
6. 检查标准品、未知样品和空白三路，再检查仪器到空白校正、校准到定量的连接，最后导出PDF或PNG。

文字、面板、公式的字母和下标、线条与箭头是原生可编辑对象；透明PNG可以独立移动和缩放，内部像素不属于可编辑矢量对象。

图中的蛋白与染料是概念图案。三路样品分别测量，共享仪器的连线不表示混样。
